# 灵感音乐工作台

## 功能

离线编曲时间线、键盘试听、灵感规则和本地项目状态。

## 技术栈

HTML、CSS、JavaScript、Web Audio。依赖版本以现有清单和上游兼容要求为准，早期代码可能需要历史版本。

## 目录

index.html 页面；styles.css 样式；app.js 交互与音频。

## 启动

在本仓库目录执行；Python 示例需先激活自行创建的虚拟环境。

```sh
python3 -m http.server 8080
# 浏览器访问 http://localhost:8080
```
